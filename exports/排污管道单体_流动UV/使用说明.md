# 排污管道单体 · 流动 UV

项目中的“排污管道单体”已更新。FBX 与 GLB 均携带相同的 UV0。

- 将材质球 `GasFlow_HDRP 底部流向` 赋给 `排污管道_红色` 节点。
- U（横向）绕管一周为 0～1；V（纵向）沿中心线从顶部接口的 0 走到底部弯头出口的 1。
- 保持材质的 `_Direction = (0, -1)`，当前 shader 用 `UV + time * Direction` 采样，因此纹理特征沿 V 增大方向移动，即从顶部向出口移动。
- 材质已有的 Tiling `(0.34, 0.7187054)` 与速度参数可继续使用，按视觉需要微调。
- 在 Unity 模型导入设置中不要启用 **Swap UVs**。本次修改的是主贴图 UV0，UV2/光照贴图不参与流动。
- 只有红色管道修改了 UV。阀门、手轮、法兰、仪表保留原来的 UV、材质及几何结构。

原模型已备份在项目模型目录的 `backups/before-flow-uv-...` 中。此处未复制或修改 Unity 材质球与 shader；在 Unity 内使用原有材质球即可。

校验：160 个管道三角面、11 个截面环，UV 无翻面，接缝连续；GLB 导出字节与 FBX 重新导入后的 UV0 均与保存数据一致。
