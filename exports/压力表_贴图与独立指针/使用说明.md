# 压力表贴图与独立指针

- 量程：已确认的 **0–1.6 MPa**，270° 表盘，2048×2048 PNG 刻度贴图。
- `压力表_表盘` 只有刻度和文字，贴图里没有指针。
- `指针` 为独立红色网格，含中心帽。它的锚点在表盘中心，局部 Z 轴朝表盘外侧；可以单独旋转、隐藏和替换材质。
- 默认示例读数为 **0.6 MPa**。模型在项目中仍名为“压力变送器”。

## Unity 中控制指针

导入 `压力表_独立指针.fbx` 或完整装配文件，找到名为 `指针` 的子物体。读取初始局部旋转后追加局部 Z 轴旋转，以兼容 FBX 坐标转换：

```csharp
// 初始化时记录当前 0.6 MPa 示例姿态。
Quaternion initialRotation = needle.localRotation;
const float initialAngle = 33.75f;

// 每次设置读数：0 MPa 对应 135°；1.6 MPa 对应 -135°。
float pressureMPa = Mathf.Clamp(value, 0f, 1.6f);
float angle = 135f - 270f * pressureMPa / 1.6f;
needle.localRotation = initialRotation * Quaternion.AngleAxis(angle - initialAngle, Vector3.forward);
```

在组件启用时只记录一次 initialRotation，后续设置读数时重复使用。若 Unity 导入后局部轴转换不同，可在 Inspector 的 Local 模式下核对旋转轴。

## 文件

- `压力变送器_完整装配.fbx/.glb`：整个装配，带新表盘和独立指针。
- `压力表_独立指针.fbx/.glb`：只包含压力表及其过程接头，表盘中心位于模型原点附近，便于复用。
- `指针_保留表盘中心轴心.fbx/.glb`：单独指针，保留在完整装配中的位置与旋转轴。
- `pressure-dial.png`：可替换的原始表盘图片。
- `压力表_刻度贴图.png`：FBX 材质引用的同内容贴图，与 FBX 保持同目录。

GLB 内嵌贴图。FBX 使用同目录 PNG；Unity 的具体材质 Shader 由渲染管线及导入设置决定。

已为指针开启导出时保留局部轴心。原模型（含 UV 和材质）在项目模型目录 `backups/before-dial-and-pointer-...` 下保留备份。
