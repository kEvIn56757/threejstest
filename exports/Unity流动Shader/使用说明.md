# 流动方向开关

原 Shader 增加 `Reverse Flow (反向流动)` 复选框，位置在材质面板的 **Flow Settings** 分组、**Flow Direction** 下方。

- 不勾选：沿原方向流动，保留所有现有材质的默认效果。
- 勾选：同时反转主贴图、细节贴图的滚动方向，以及 Flow Progress 的填充推进方向（包括 Timeline 中的进度动画）。
- 模型继续使用同一份 UV0。无需反向 UV 或另一套模型。
- 原有 `_Direction`、速度、Tiling、颜色和渐变保持不变；反转时进度遮罩从另一端推进。

在 Unity 内选择材质 `GasFlow_HDRP 底部流向`，勾选该开关即可。所有使用同一个 Shader 的材质都能看到此开关，各材质分别保存开关状态。

运行时按钮或 Toggle 可控制材质属性，无需切换 shader keyword：

```csharp
// 使用该物体的材质实例，避免同时影响其他使用同一材质的物体。
Material flowMaterial = targetRenderer.material;
flowMaterial.SetFloat("_ReverseFlow", reverse ? 1f : 0f);
```

如使用 MaterialPropertyBlock 控制单个 Renderer：

```csharp
var block = new MaterialPropertyBlock();
targetRenderer.GetPropertyBlock(block);
block.SetFloat("_ReverseFlow", reverse ? 1f : 0f);
targetRenderer.SetPropertyBlock(block);
```

工作区保留了修改后的 Shader 和 `backup/GasFlow_HDRP.shader.original` 原始备份。原 `.mat` 贴图引用和 Shader `.meta` GUID 均无需修改。
